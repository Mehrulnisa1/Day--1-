# Python Loops

This project covers the basics of Python loops and loop control.

## Topics Covered

* **For Loop** – Iterating through sequences like lists, strings, and tuples.
* **While Loop** – Repeating code while a condition is `True`.
* **`for...in`** – Accessing each item from a collection.
* **`range()`** – Generating number sequences using `start`, `stop`, and `step`.
* **For + Range** – Using `range()` with a `for` loop.
* **Start, Stop & Step** – Controlling where a loop starts, ends, and how it moves.
* **Break** – Completely stops the loop.
* **Continue** – Skips the current iteration and continues the loop.
* **Increment & Decrement** – Increasing or decreasing values using `+=` and `-=`.
* **Pre/Post Increment** – Python does not support `++` or `--`; it uses `+= 1` and `-= 1`.
* **Nested Loops** – Using one loop inside another loop.
* **Pass** – Used as a placeholder when no action is required.

## Key Difference

```text
break     → stops the loop
continue  → skips current iteration
pass      → does nothing
```

## Requirements

No external packages are required. This project uses Python's built-in features.
