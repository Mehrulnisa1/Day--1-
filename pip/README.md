# Python pip

## What I Learned

In this project, I learned about `pip` — what it is, why it is used, and how to install and manage Python packages.

## Motive

The main motive was to understand how Python packages are installed and managed in a project.

Instead of writing everything from scratch, we can use packages created by other developers to add useful functionality to our projects.

## What is pip?

`pip` is Python's package installer. It is used to install, update, remove, and manage Python packages.

For example:

```bash
pip install numpy
```

This installs the NumPy package in the active Python environment.

## Why is pip Important?

`pip` helps to:

* Install Python packages
* Update packages
* Remove packages
* Check installed packages
* Manage project dependencies

## How to Check pip

To check whether pip is available:

```bash
pip --version
```

This shows the installed pip version and its location.

## How to Install a Package

To install a package:

```bash
pip install package-name
```

Example:

```bash
pip install numpy
```
